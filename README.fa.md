# پرایم‌اواس (Prime-OS)

پروژهٔ جامعه‌محور برای ساخت یک سیستم‌عامل گیمینگ بر پایهٔ **Arch Linux** و محیط گرافیکی **Hyprland** است. مرحلهٔ فعلی فقط یک **نسخهٔ زنده و آزمایشی ISO** است؛ هنوز نصب‌کننده یا سیستم‌عامل آمادهٔ استفادهٔ روزمره نیست.

> نمی‌شود بدون آزمایش روی سخت‌افزار مشخص قولِ «بدون لگ» داد؛ سرعت بازی به کارت گرافیک، درایورها، خود بازی و قطعات سیستم بستگی دارد. اول ISO را در ماشین مجازی امتحان کن. برای تست روی کامپیوتر واقعی، از فلش خالی استفاده کن و از اطلاعات مهم پشتیبان بگیر.

## امکانات نسخهٔ آزمایشی

- محیط زندهٔ Arch Linux با ابزار رسمی `archiso`.
- میزکار Wayland/Hyprland همراه Waybar و Wofi.
- Steam، Lutris و بسته‌های رایج Mesa/Vulkan.
- کاربر زندهٔ معمولی با نام `prime`.
- ساخت تصویر خروجی با نام `out/os.iso`.
- لودر سازگار با Windows، Linux و macOS؛ در ویندوز از فونت Segoe UI (در صورت وجود) استفاده می‌کند و ماژول تصویری `you.py` را بدون اجرای خودکار بارگذاری می‌کند.

این ISO فعلاً سیستم‌عامل را روی دیسک نصب نمی‌کند. نصب‌کننده، Secure Boot، بازیابی سیستم و بهینه‌سازی سخت‌افزاری هنوز پیاده‌سازی و آزمایش نشده‌اند. یک ISO واحد هم نمی‌تواند همهٔ درایورهای اختصاصی GPUها را در خود داشته باشد.

## اجرای ویزارد در ویندوز

Python 3 (با گزینهٔ Tcl/Tk) و Git for Windows را نصب کن، سپس PowerShell را باز کن و اجرا کن:

```powershell
irm https://raw.githubusercontent.com/fem-dev/Prime-OS/main/install.ps1 | iex
```

این کار ویزارد نمایشی را در ویندوز اجرا می‌کند؛ ویندوز را پاک یا جایگزین نمی‌کند. اطلاعات برنامه در `%LOCALAPPDATA%\\Prime-OS` و ترجیحات در `%APPDATA%\\Prime-OS` ذخیره می‌شود.

## ساخت ISO

سازنده Arch Linux را درون یک کانتینر جداگانهٔ Docker اجرا می‌کند؛ لازم نیست Linux را روی ویندوز نصب کنی. Docker باید نصب و در حال اجرا باشد. ساخت به اینترنت و چند گیگابایت فضای خالی نیاز دارد.

```bash
git clone https://github.com/fem-dev/Prime-OS.git
cd Prime-OS
docker run --rm --privileged \
  -e PRIME_OS_BUILD_CONTAINER=1 \
  -v "$PWD:/work" \
  -w /work \
  archlinux:latest \
  bash -lc 'pacman -Syu --noconfirm archiso && PRIME_OS_BUILD_CONTAINER=1 bash ./build.sh'
```

اگر ساخت موفق شود، فایل `out/os.iso` ساخته می‌شود. فعلاً ISO ازپیش‌ساخته‌ای در GitHub منتشر نشده است. `build.sh` را با sudo روی سیستم اصلی اجرا نکن.

## اجرای آزمایشی

فایل `out/os.iso` را در ماشین مجازی UEFI (مثلاً QEMU یا VirtualBox) بوت کن یا با برنامهٔ نوشتن image روی یک فلش خالی بنویس. بوت ISO چیزی را روی کامپیوتر نصب نمی‌کند. مراقب باش فلشی را که فایل مهم دارد پاک نکنی.

کلیدهای شروع در Hyprland:

- `Super + Enter`: ترمینال
- `Super + D`: فهرست برنامه‌ها
- `Super + G`: Steam
- `Super + B`: مرورگر
- `Super + N`: تنظیمات شبکه
- `Super + M`: خروج از Hyprland

## وضعیت پروژه

اولین قدم بعدی، ساخت ISO در محیط Arch و بوت‌کردن آن در ماشین مجازی است؛ بعد باید مشکلات راه‌اندازی و سازگاری روی سخت‌افزارهای مختلف بررسی شود. پس از آن می‌توان سراغ نصب‌کننده، به‌روزرسانی امن و بهینه‌سازی‌های قابل‌اندازه‌گیری رفت.
